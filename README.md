# JS_TS_Programming_Practice

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)

A personal playground for practicing core programming concepts in **JavaScript** and **TypeScript**, covering basics, algorithms, and small exercises to sharpen fundamentals.

---

## 📁 Repository Structure

| Folder | Description |
|--------|-------------|
| `Basic_Program_Codes/` | Fundamental programs: variables, operators, conditionals, loops, and functions |
| `Arrays_Program_Codes/` | Array manipulation problems: searching, sorting, reversing, merging, and more |
| `String_Based_Program_Code/` | String problems: palindromes, anagrams, character counts, reversal, etc. |
| `Number_Based_Questions/` | Number-based problems: prime, factorial, Fibonacci, Armstrong, GCD/LCM, etc. |
| `Pattern_Program_codes/` | Pattern printing programs: stars, pyramids, triangles, and number patterns |
| `InterfacesProgram_Codes/` | TypeScript practice on interfaces, typing, and object structures |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm (comes with Node.js)
- TypeScript (for `.ts` files)

```bash
npm install -g typescript ts-node
```

### Clone the Repository

```bash
git clone https://github.com/RoshanGhadge20/JS_TS_Programming_Practice.git
cd JS_TS_Programming_Practice
```

### Run a JavaScript File

```bash
node Basic_Program_Codes/fileName.js
```

### Run a TypeScript File

```bash
# Using ts-node
ts-node InterfacesProgram_Codes/fileName.ts

# Or compile first, then run
tsc InterfacesProgram_Codes/fileName.ts
node InterfacesProgram_Codes/fileName.js
```
